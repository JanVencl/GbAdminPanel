# GbAdminPanel

Web admin panel for [GraphBuff](https://github.com/JanVencl/graphbuff) — control, inspect and manage GraphBuff servers.

## Stack

- **Frontend:** React
- **Backend:** Java / Spring Boot
- **Connectivity:** Neo4j Java driver (Bolt) to GraphBuff

## Status

Early development.
